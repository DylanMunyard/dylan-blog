Action button — one mint `primary` per view; `secondary` for neutral, `ghost` for tertiary, `danger` rarely.

```jsx
<Button variant="primary">Read post →</Button>
<Button variant="secondary" size="sm">Copy</Button>
```

Props: `variant` primary|secondary|ghost|danger, `size` sm|md|lg, `href` renders an `<a>`, `disabled`. Press scales to 0.98; hover brightens.
